# Data Labeling Portfolio

## About This Portfolio
This portfolio showcases my expertise in **Text Labeling** and **Image Labeling**, including advanced QA processes and dataset structuring. It is designed to demonstrate professional annotation skills.

## Highlights
- **Text Labeling**: Classification, Named Entity Recognition (NER), Intent Classification, Topic Labeling
- **Image Labeling**: Classification, Object Detection, Segmentation, Keypoints
- **Quality Assurance (QA)**: Accuracy, consistency, and completeness across all tasks
- **Dataset Export**: COCO JSON, Pascal VOC XML, YOLO TXT, plus JSON/CSV for text

## Repository Structure
- `Text_Labeling/` → JSON examples of text annotation tasks
- `Image_Labeling/` → JSON examples of image annotation tasks
